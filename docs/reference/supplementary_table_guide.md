# Supplementary-table guide

Our supplementary materials contain the primary result tables. We point readers to those tables rather than maintaining a second copy of the results.

| Table | Contents | Useful for |
|---|---|---|
| ST1 | Comparisons of significant association or enrichment proportions across deletions, duplications, and SNPs | Variant-class comparisons |
| ST2 | Brain-versus-non-brain comparisons across variant types and gene-set collections | Functional burden pleiotropy comparisons |
| ST3 | Sex-difference statistics for mental-health traits | Sex-aware interpretation |
| ST4 | Gene-set-category comparisons across trait categories | Brain and non-brain specificity |
| ST5 | Constraint–pleiotropy correlations with overlap-aware p-values | Constraint analyses |
| ST6 | CNV length and protein-coding gene-content properties | CNV descriptive statistics |
| SD1 | Demographics and summary of 43 UK Biobank traits plus four All of Us replication traits | Phenotype definitions and sample sizes |
| SD2 | Ensembl gene IDs × 172 gene sets membership matrix | Reconstructing functional sets |
| SD3 | Jaccard overlap between all 172 gene-set pairs | Gene-set overlap analyses |
| SD4 | FunBurd estimates for 43 traits × 172 gene sets, including inside-set and outside-set effects for deletions and duplications | Primary association results |
| SD5 | Brain-versus-non-brain comparisons across sensitivity analyses | Robustness checks |
| SD6 | All of Us replication FunBurd estimates for four traits × 172 gene sets | Cross-cohort replication |
| SD7 | Sign-concordance statistics between All of Us and UK Biobank | Replication summary |
| SD8 | Aggregated predicted loss-of-function burden estimates from GeneBass | Deletion–pLoF comparison |
| SD9 | Sex-stratified FunBurd estimates | Female and male analyses |
| SD10 | S-LDSC functional enrichments across 172 gene sets | Common-variant comparison |
| SD11 | Gene-set-level pleiotropy, constraint, normative-null, CNV-targeting, and dosage-response metrics | Advanced functional interpretation |
| SD12 | Between-trait phenotypic, CNV-burden, pLoF-burden, and SNP-based correlations | Cross-trait architectures |
| SD13 | Cross-variant concordance statistics for between-trait correlations | Variant-class comparison |
| SD14 | Trait-level variance explained, deletion–duplication overlap, correlations, and dosage-response counts | Trait-level summaries |
| SD15 | BMI mediation analysis for selected correlated trait pairs | Direct versus mediated pleiotropy |


## Column dictionary

The supplementary workbook includes an `ST_column_key` sheet describing the columns in each table.
